# Easy Word Quiz

A small trivia game with simple, everyday words and easy questions.

## How it works

- Open the project in a browser.
- The game shows one question at a time.
- Each question has a timer.
- Choose the correct answer before time runs out.
- Your score increases for each correct answer.
- After the last question, the final score is shown.

## Tips for building the project

- Keep the code simple and easy to read.
- Use clear question and answer names.
- Make sure the timer resets correctly for each new question.
- Test the game in the browser after each change.
- Add more questions by editing the array in `trivia.js`.
- Use small updates instead of changing too much at once.
- Check that buttons and score updates still work after editing.

## How to run the game

1. Open a terminal in the project folder.
2. Run: `python3 -m http.server 8000`
3. Open your browser and go to: `http://localhost:8000`
4. The quiz page should load and you can start playing.
